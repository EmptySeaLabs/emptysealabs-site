# Empty Sea Labs mark

A gull perched on a piling in a two-crested swell, under a crescent moon. It also hides the initials M (the swell), T (the piling and wings) and C (the moon).

| File | Use |
| --- | --- |
| `mark.svg`, `mark-512.png` | Teal mark on a transparent background, for dark surfaces |
| `mark-on-light.svg` | Deep-teal mark for light surfaces |
| `avatar.svg`, `avatar-500.png` | GitHub org avatar (dark mark on a teal square) |
| `/favicon.svg`, `/apple-touch-icon.png` | Site favicon and iOS home-screen icon |

Colors: sea `#5fd4c4`, deep sea `#1d8f86`, night `#06090c`.
